# Metaclouds 算力调度平台 · 界面设计方案（v2.0）

> 交付物：可交互高保真原型 `metaclouds-ui-prototype.html` + 本规范文档
> 适用范围：Web 控制台（桌面优先，兼容平板）
> 技术基线：React 18 + antd 5.12 + Tailwind 3.4 + ECharts 5.4

---

## 一、设计目标与原则

### 1.1 目标用户

| 角色 | 核心诉求 | 主要页面 |
|------|----------|----------|
| 平台管理员 | 全局水位、故障定位、配额治理 | 仪表盘、监控告警、多租户 |
| 调度运维 | 作业吞吐、队列健康、节点状态 | 作业管理、K8S 管理 |
| 算法工程师（租户） | 快速提交作业、查看结果 | 作业管理、资源管理 |

### 1.2 四条设计原则

1. **信息优先（Data-first）** —— 算力平台的核心资产是数据。装饰服从于可读性：数字用等宽对齐、状态用「色点 + 文字」、表格密度可调，杜绝"好看但读不到数"。
2. **一致性优先（Consistent）** —— 全站共用一套令牌（颜色 / 间距 / 圆角 / 阴影 / 动效）。任何页面新增样式，先问"能否复用既有令牌"。
3. **可预测（Predictable）** —— 同类操作位置固定：主操作在右上、批量条在表格上方、分页在左下、危险操作恒为红色 + 二次确认。
4. **容错（Forgiving）** —— 破坏性操作可撤销或二次确认；空态/错误态必须给出下一步动作；失败提示说明"为什么"和"怎么办"。

## 二、信息架构（IA）

```
Metaclouds 控制台
├─ 总览
│   └─ 仪表盘                     算力水位 / 吞吐 / 风险
├─ 调度
│   └─ 作业管理 ├ 作业列表  ├ 任务队列  └ 历史记录
├─ 基础设施
│   ├─ 集群管理
│   ├─ 资源管理
│   └─ K8S 管理 ├ 节点管理 ├ Pod 管理 └ 服务管理（按命名空间/租户）
├─ 平台
│   ├─ 多租户管理
│   └─ 加速套件
└─ 可观测与治理
    ├─ 监控告警
    └─ 安全管理
```

**相对现状的调整**

| 项 | 现状 | 方案 | 理由 |
|----|------|------|------|
| 导航分组 | 9 项平铺 | 5 个业务域分组 | 降低扫视成本，符合"先分类再定位"的心智 |
| 顶栏 | 无 | 新增 56px 全局顶栏 | 承载搜索、环境、通知、主题、用户，是控制台的必备区 |
| 仪表盘位置 | 第 1 项 | 保持第 1 项 | 登录后的默认落点，符合"先总览后深入" |
| K8S 管理 | 排在末尾 | 移入「基础设施」紧邻集群/资源 | 同属基础设施关注面，避免跨组跳转 |
| 监控告警 | 夹在租户与加速之间 | 移入「可观测与治理」 | 与安全管理同属治理类动作 |

## 三、设计令牌（Design Tokens）

### 3.1 色彩

**品牌色 —— Quantum Blue 量子蓝**

| 变量 | 色值 | 用途 |
|------|------|------|
| brand-700 | `#1B47C4` | 按下态 |
| brand-600 | `#1F52E0` | 悬停态、次级文字强调 |
| brand-500 | `#2F6BFF` | **默认主色**（主按钮、选中、关键链接） |
| brand-400 | `#5B8BFF` | 深色模式主色 |
| brand-100 | `#DCE8FF` | 描边 |
| brand-50 | `#EEF4FF` | 底色（选中行、信息提示） |

**语义色**

| 语义 | 色值 | 含义 |
|------|------|------|
| success | `#12B886` | 健康 / 完成 / 可分配 |
| warning | `#F59E0B` | 排队 / 高负载 / 警告（>80% 配额亦用此色） |
| danger | `#F0445A` | 失败 / 严重 / 破坏性操作 |
| teal | `#00B8A9` | 运行中 / 推理类 |
| violet | `#7C5CFF` | 训练类 / 加速套件 |
| muted | `#7C8DA6` | 停用 / 维护 / 未启用 |

**中性色**

| 变量 | 色值 | 对比度（对 #FFF） | 用途 |
|------|------|-------------------|------|
| text-1 | `#0E1726` | 15.8:1 | 标题、正文 |
| text-2 | `#4A5B75` | 7.4:1 | 次级信息 |
| text-3 | `#7C8DA6` | 3.6:1 | 辅助、占位（仅用于非关键文本） |
| line | `#E4EAF3` | — | 分割线、卡片描边 |
| surface | `#FFFFFF` | — | 卡片、浮层 |
| bg | `#F5F7FC` | — | 页面底色 |

> **使用约束**：一屏内主按钮（brand-500 实心）不超过 1 个；红色仅用于危险与严重，不得用于"数值上升"；颜色永远搭配文字或图标，禁止单独表意。

**深色模式**：`--surface #111A2B`、`--bg #0A1120`、`--line #22304A`、`--text-1 #EAF0FA`；品牌主色切换为 brand-400，语义色整体提亮一档以维持对比度。

### 3.2 字体

- **字体族**：`Inter, "HarmonyOS Sans SC", "PingFang SC", "Microsoft YaHei", system-ui`
- **数字**：`font-variant-numeric: tabular-nums`（表格、KPI、时间）—— 防止数值跳动
- **代码 / ID**：`JetBrains Mono, SFMono-Regular, Consolas, monospace`

| 层级 | 字号 / 字重 / 字距 | 用途 |
|------|--------------------|------|
| H1 | 30 / 680 / -0.8px | 页面主 KPI 数值 |
| H2 | 22 / 660 / -0.3px | 页面标题 |
| H3 | 15 / 620 / 0 | 卡片标题 |
| Body | 14 / 400 / 0，行高 1.5 | 正文、表格 |
| Caption | 12 / 400 / 0 | 辅助说明、时间戳、单位 |
| Metric | 30 / 680 / -1px + tabular | KPI 数值 |

### 3.3 间距 / 圆角 / 阴影 / 动效

- **间距**：4pt 栅格 —— `4 8 12 16 20 24 32 40 48`；卡片内边距 20px，卡片间距 16px，页面边距 24px。
- **圆角**：`4 / 6 / 8 / 12 / 16 / 999`。控件 8px，卡片 12px，标签 6px，头像与开关用 pill。
- **阴影**（由静到动）：

| 令牌 | 值 | 场景 |
|------|-----|------|
| sh-1 | `0 1px 2px rgba(14,23,38,.06)` | 卡片静止 |
| sh-2 | `0 2px 6px rgba(14,23,38,.06)` | 卡片悬停 |
| sh-3 | `0 8px 24px rgba(14,23,38,.08)` | Toast / 下拉浮层 |
| sh-4 | `0 18px 48px rgba(14,23,38,.16)` | 模态 / 抽屉 / 命令面板 |

- **动效**：缓动统一 `cubic-bezier(.2,.8,.2,1)`；微交互 120ms，浮层/展开 180ms，页面切换 280ms。全局遵循 `prefers-reduced-motion`。

## 四、布局与页面模板

### 4.1 全局骨架

```
┌────────────┬──────────────────────────────────────────┐
│            │ 顶栏 56px：面包屑 · 搜索⌘K · 环境 · 通知 │
│  侧边栏    ├──────────────────────────────────────────┤
│  248px     │ 页面头：标题 + 描述        主要操作（右） │
│  （分组）  ├──────────────────────────────────────────┤
│            │ 筛选栏 → 批量条 → 内容卡片 → 分页        │
└────────────┴──────────────────────────────────────────┘
```

- 内容栅格 12 列，gutter 16/24；宽屏 KPI 用 4 列，图表区常用 `2fr : 1fr`。
- 表格采用**粘性表头**；分页固定左下；行内操作默认 55% 透明度，hover 显现，避免视觉噪声。

### 4.2 页面模板（每个业务页统一）

1. **PageHeader**：H2 标题 + 13px 描述（说明数据口径/刷新频率）+ 右侧操作区（筛选时间范围 → 次要操作 → 主操作）。
2. **筛选区**：搜索框 + 2~3 个下拉 + 「更多筛选」；右侧密度切换（紧凑/标准/宽松）。
3. **批量操作条**：勾选后出现，显示「已选择 N 项」，右侧为批量动作 + 取消选择。
4. **内容区**：表格/图表/卡片。
5. **分页**：左下「共 N 条 · 每页 M 条」，右侧页码。

## 五、组件规范

### 5.1 按钮

| 类型 | 样式 | 规则 |
|------|------|------|
| 主按钮 | brand-500 实心 + 轻投影 | 一屏仅 1 个，居操作区最右 |
| 次按钮 | 白底 + line-strong 描边 | 可并列多个 |
| 危险按钮 | red-500 实心 | 必须二次确认（输入对象名） |
| 禁用 | opacity .5 + not-allowed | 需配合 Tooltip 说明原因 |

高度：表格内 32px，表单与页面级 42px。

### 5.2 输入与表单

- 高度：表格筛选 34px，表单 42px。
- 错误态：红描边 + 3px 红环 + **字段下方内联文案**（禁止用 alert 弹窗）；提交时焦点自动跳到首个错误字段。
- 必填用红色 `*`；复杂约束在标签右侧放帮助图标说明。
- 密码框保留「显示密码」，登录失败统一文案（不区分"用户不存在/密码错误"，防账号枚举）。

### 5.3 表格

- 粘性表头、斑马纹（可选）、hover 高亮、选中行 brand-50。
- 列设置（显示/隐藏/排序）、密度切换、横向滚动时首列冻结。
- 长 ID 用等宽 + 淡底标签；状态用「色点 + 文字」；进度用 6px 圆角条，>80% 转警示色。
- 空数据、加载、错误三态必须成套实现。

### 5.4 状态与反馈

| 状态 | 表现 |
|------|------|
| 排队中 | amber 实心点 + 文字 |
| 运行中 | teal/brand 点 + `pulse` 呼吸动画（2s） |
| 已完成 | green 点 |
| 失败 | red 点 + 错误信息可展开 |
| 已取消 / 维护 | muted 灰点 |

- **加载**：首屏用骨架屏（≥3 行），局部刷新用内联 spinner，禁止整页遮罩。
- **Toast**：右上角/右下角 3s 自动消失；错误 Toast 常驻至手动关闭。
- **危险操作**：`删除/取消/下线` 一律二次确认；批量场景要求输入名称确认。

### 5.5 命令面板（⌘K / Ctrl+K）

新增全局能力：搜索页面、按 ID 定位作业、执行常用动作（新建作业、切主题、查队列）。
交互：⌘K 唤起 → 输入过滤 → ↑↓ 选择 → ↵ 执行 → Esc 关闭；分组标题区分「快捷操作 / 跳转到 / 作业」。

## 六、关键页面设计说明

### 6.1 登录页

- **左品牌区**：深空渐变 + 网格纹理 + 光斑，承载价值主张与三项关键指标（集群数 / 调度成功率 / 平均排队时长）。
- **右表单区**：单列 380px，字段 2 个，含记住我、忘记密码、SSO 分隔。
- 设计要点：首屏即展示产品价值而非空白；错误内联；移动端隐藏品牌区，单列表单居中。

### 6.2 仪表盘

- 4 张 KPI 卡（GPU 利用率 / 运行中作业 / 排队中作业 / 活跃告警），每张含数值、环比 delta、迷你趋势线（sparkline）。
- 主图表：算力使用趋势（GPU/CPU 双序列面积图 + 容量参考线）；右侧资源分布环形图（已用/预留/可分配/维护）。
- 下方：待处理告警（按严重度排序，带「处理」入口）+ 最近作业表。
- 顶部提供时间范围切换、刷新、自定义卡片布局、提交作业。

### 6.3 作业管理

- 状态 Tabs 带计数（全部 32 / 排队 6 / 运行 2 / 完成 18 / 失败 4 / 取消 2）。
- 表格列：ID（等宽标签）、名称、类型标签、GPU 数、队列/租户两行、状态、进度条、提交时间、行内操作。
- 勾选触发批量条；页内同时示范空态与骨架屏两种边界态。

### 6.4 K8S 管理（服务管理语义重构）

- **命名空间 = 租户边界**：顶部 Segmented 切换命名空间。
- 左侧「命名空间配额」：GPU/CPU/内存/存储 四项「已用/总量」进度条，>80% 转警示色；已用量取自**运行中作业的实际占用**。
- 右侧「服务清单」：服务 = 命名空间内可调度的算力单元（GPU 池、网关、调度器、存储、采集），含容量/已用/利用率/健康状态。
- 保留了原集群表的字段价值，但把语义从「集群即服务」纠正为「命名空间内的服务」。

### 6.5 监控告警

- 顶部按等级分列（严重 1 / 警告 1 / 提示 1 / 今日已恢复 9），每列标注响应时限。
- 告警趋势 14 天堆叠柱状图（提示/警告/严重三色）。
- 告警列表含级别、名称、影响对象、当前值、触发时间、持续时长、状态、操作。

## 七、响应式与无障碍

**断点**：1440 / 1280 / 1024 / 768

| 宽度 | 表现 |
|------|------|
| ≥1440 | 完整四列 KPI，侧边栏展开 248px |
| 1280 | KPI 转两列，图表 `1.6fr : 1fr` |
| ≤1024 | 侧边栏收为 72px 图标态，图表单列，搜索框收窄 |
| ≤768 | 侧边栏转抽屉（遮罩关闭），内容边距 16px，表格转卡片流 |

**无障碍基线**

1. 正文对比度 ≥ 4.5:1，大字与图形元素 ≥ 3:1。
2. 所有可交互元素有可见焦点环（2px brand-500，offset 2px）。
3. 触达目标 ≥ 40×40px。
4. 颜色不是唯一信息载体（状态 = 色点 + 文本）。
5. 支持键盘全流程操作，浮层 Esc 关闭，动效遵循 `prefers-reduced-motion`。
6. 图标按钮必须带 `aria-label`/Tooltip。

## 九、原型使用说明

原型为**单文件离线 HTML**（`metaclouds-ui-prototype.html`），双击即可打开：

1. 首屏为登录页，点击「登录」进入控制台。
2. 左侧导航可切换 5 个页面；「作业管理」「K8S 管理」可展开子菜单。
3. 右上角搜索框或 `Ctrl/⌘ + K` 唤起命令面板；`Esc` 关闭。
4. 右上角月亮图标切换深色 / 浅色模式。
5. 作业管理页勾选表格行，可查看批量操作条；页内可查看空态与骨架屏示例。
6. 「设计系统」页集中展示色板、字体阶梯、圆角/阴影/间距、组件规范与改版前后对照。

> 所有图表均为手绘 SVG，无外部依赖与网络请求，可离线演示。
