交互约定

① 全局命令面板：Ctrl/⌘ + K，支持跳转页面、搜索作业 ID、执行常用动作。
② 批量操作：勾选后底部出现操作条，明确「已选择 N 项」，危险操作需输入名称二次确认。
③ 破坏性操作：删除 / 取消一律红字 + 二次确认；不使用纯图标垃圾桶。
④ 加载与空态：首屏用骨架屏（≥3 行），不用整页 spinner；空态必须给出下一步动作。
⑤ 反馈时效：≤1s 无反馈需 loading；成功用 Toast（3s 自动消失），失败保留至手动关闭。
⑥ 表格：粘性表头、列设置、密度切换、分页固定在左下，行内操作悬停显现。

响应式与无障碍

① 断点：1440 / 1280 / 1024 / 768；≤1024 侧边栏收为图标态，≤768 转抽屉 + 底部标签栏。
② 触达目标 ≥ 40×40px；行高与点击区间分离，避免误触。
③ 所有交互元素可见焦点环（2px 品牌色，offset 2px）。
④ 颜色不是唯一信息载体：状态必须同时具备「色点 + 文字」。
⑤ 支持键盘全流程操作与 Esc 关闭浮层；动效遵循 prefers-reduced-motion。
⑥ 表格支持横向滚动与列冻结，移动端转为卡片流。

改版前后对照

关键体验差异
✕ 现状问题
· 无顶栏：缺全局搜索、环境标识、通知与用户区
· 菜单子项点击后视图不切换，等同死链
· 卡片与表格沿用组件默认样式，层级靠阴影堆叠
· 空态 / 加载态缺失，出错时页面空白
· 破坏性操作无二次确认，批量操作无反馈
· 数字使用比例字体，表格列跳动
✓ 方案改进
· 顶栏承担「搜索 · 环境 · 通知 · 主题 · 用户」全局能力
· 侧边栏分组 + 路由联动，子项切换真实视图
· 统一令牌：一套色板、四级阴影、8pt 节奏贯穿全流程
· 骨架屏 / 空态 / 错误态成套，空态必给下一步动作
· 危险操作二次确认，批量操作条常驻可见
· 指标数字 tabular-nums 对齐，长 ID 用等宽字体
