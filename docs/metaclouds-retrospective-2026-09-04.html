1项目概览

一页读懂「这是一个什么样的项目」

定位：企业级云资源管理平台（算力调度平台），提供 GPU 加速计算资源管理、Kubernetes 集群管理、作业调度、监控告警等核心能力，面向多租户的 AI 训练与推理场景。

架构风格：集成式单体（Integrated Monolith），为后续微服务拆分预留边界。

② P0 凭据轮换与安全加固2026-08-30 ~ 08-31安全攻坚

发现两处严重问题：真实 .env 曾被 force-add 入库、默认口令 Admin@123! 硬编码。采取 8 步闭环：完整备份 → 代码去硬编码（bootstrap_credentials.go 生产缺失即拒启动）→ 轮换全部凭据（≥24 字符）→ git filter-branch 重写历史（27MiB→279KiB，密钥零残留）→ pre-commit 密钥扫描钩子 → 前端泄露提示清理与 dist 脱敏 → 外部轮换 runbook + rotate_*.sh 可执行脚本 → K8s secrets 改为 fail-secure 模板。

同期完成 MDS 设计系统（UI 高保真原型 + 设计规范）与 8 个业务页面 MDS 收口，后端扁平化纳入单一仓库（3 笔本地提交）。

③ 全栈 RBAC 与质量收敛2026-09-01权限收敛

后端：pkg/authz 完整接入路由，写操作/敏感资源全部挂 RequirePermission（越权请求 403）；注册开关、令牌续期死机制移除、中间件栈统一；租户/作业/集群/资源负值入参以 400 拒绝；go test -race 实证无数据竞争。

前端：全站消除 any 类型化；401 处理修复；菜单/路由按 role 收敛（/tenant 仅 admin/manager）；profile/refresh 契约对齐 + 静默续期；操作级写按钮用 <Can> 收敛 16 处。

验证：引入 CDP 真实浏览器（无头 Chrome）验证登录流、RBAC 接线、按钮可见性；交付 docs/rbac-permission-convergence.md 前后端对照清单。

④ 前端响应式改版2026-09-02体验升级

PRD 目标「自适应不同分辨率 + 国际一流水准」被拆解为 8 项可测量目标（G1–G8：零横向溢出、零遮挡、零 JS 布局抖动、8 档断点连续覆盖、44px 触控、超宽屏收敛、功能零回归、暗色零回归）。

M1 地基：8 档断点单一真相源 + 纯 CSS Grid 布局（去 window.innerWidth）+ 侧边栏 Drawer/遮罩/Esc + Tailwind 接入；M2 表格卡片化：ResponsiveTable 接入 10 张表（scroll.x 硬编码归零）；M3 仪表盘：DraggableGrid 断点 span + ResponsiveChart ResizeObserver 令牌化高度；M4 补齐：触控 44px 命中区、弹窗窄屏全屏、登录页 clamp，并以四档视口 × 明暗双主题 CDP 走查全绿收口。

续项：R3-b 侧边栏宽度真相合并、Q6 密度切换（紧凑/舒适）、R15 内联魔法值收敛、R19 监控页分栏、vendor chunk 拆分（echarts/antd/react-vendor/vendor）。

5做得好的地方

沉淀为团队 SOP 的可复用实践
  • 安全优先、纵深防御：P0 凭据事件从备份 → 轮换 → 历史重写 → 钩子防再发全链路闭环，且每步可逆（bundle 回滚）。
  • 先实证再动配置：一度假设 sqlite 需 CGO 会破坏 CGO_ENABLED=0，经强制全量重编译实证假设不成立后回退，避免静态二进制退化。
  • 破坏性操作前征求用户：面对「无共同祖先」强制推送，摆清三个选项与后果让用户拍板，而非自行决定。
  • 覆盖前抢救存量内容：强制推送前将远端真实 README 并入本地历史（c119538），零丢失。
  • 验证不靠「构建绿」：引入 CDP 真实浏览器（Fetch 域注入假数据信封）做四档视口 × 明暗双主题走查，把「构建通过」与「行为正确」分开证明。
  • 网络失败按间歇性处理：单次 push 失败不判死，重试循环第 3 次即成功；管道退出码判断（git push | tail 会误报）教训已沉淀。
  • 文档贯穿始终：PRD、设计文档、复盘报告、部署 Runbook、权限对照清单、验证报告六类文档齐备且互相引用。
